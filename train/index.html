# 训练系统核心主线

本主线聚焦于**超大规模大语言模型（LLM）分布式训练系统**的核心技术，以 Ultra-Scale Playbook 与现代工业界训练实践为基准，覆盖显存/通信账本推导、并行模式切分与 5D 并行综合系统设计。

## 学习目标

完成本系列 14 课学习后，你将具备：

1. **精准显存账本**：独立推导参数、梯度、优化器状态与激活值在不同精度和并行策略下的常驻显存与峰值显存；
2. **通信代价建模**：熟练推导 Ring AllReduce、ReduceScatter、AllGather 等通信原语的单卡通信量与延迟/带宽模型；
3. **5D 并行切分实战**：能够根据具体集群规模（GPU 卡数、NVLink 域、节点拓扑）组合 DP/ZeRO、TP、SP、CP、PP 与 EP；
4. **性能调优与故障排查**：掌握 Prefetch 重叠、重计算（Activation Checkpointing）、算子融合与混合精度训练的工程边界。
