第 17 课：训练框架工程实操：Megatron-Core 体系与 torchtitan 架构解耦

本课目标与通过标准

掌握工业级千卡/万卡大模型训练系统的工程骨架。深入拆解 Megatron-Core（MCore） 的五维进程组（ProcessGroup）构建逻辑、Distributed Optimizer 的通信-计算重叠流水线与物理拓扑亲和性；理解 PyTorch 原生训练方案 torchtitan 的 Composable 架构，掌握基于 DeviceMesh、DTensor 与 FSDP2 的全图编译（torch.compile）与无锁异步调度。

源码版本与阅读方法

聚焦“高维网格物理映射”心智。基准：Megatron-Core 标签 core_v0.7.0、TorchTitan arXiv:2410.06511；参考 NVIDIA/Megatron-LM、pytorch/torchtitan。

顺序 核心文件与模块 带着什么问题读
1 Megatron-LM parallel_state.py 全局 Rank 如何按 order（默认 tp-cp-ep-dp-pp）分解映射为局部通信组？
2 Megatron-LM distrib_optimizer.py 优化器状态如何切分？梯度 Reduce-Scatter 与参数 All-Gather 如何双向重叠？
3 torchtitan train.py 原生 PyTorch 模块如何通过 Composable API 无侵入挂载并行策略与 DTensor 分片？
4 torchtitan components/checkpointer/ 分布式检查点（DCP）如何摆脱单卡存全量与跨机死锁实现异步秒级落盘？
