1. 它是什么，解决什么问题

强化学习（Reinforcement Learning）的数学基石是马尔可夫决策过程（Markov Decision Process, MDP）。一个标准的离散时间 MDP 由五元组构成： \[ \mathcal{M} = \langle \mathcal{S}, \mathcal{A}, \mathcal{P}, \mathcal{R}, \gamma \rangle \] - \(\mathcal{S}\)：状态空间（State Space），必须满足马尔可夫性质：\(P(s_{t+1} \mid s_t, a_t, \dots, s_0, a_0) = P(s_{t+1} \mid s_t, a_t)\)，即“未来独立于过去，仅取决于现在”； - \(\mathcal{A}\)：动作空间（Action Space）； - \(\mathcal{P}(s' \mid s, a)\)：环境状态转移概率矩阵； - \(\mathcal{R}(s, a)\)：即时奖励函数（Immediate Reward）； - \(\gamma \in [0, 1]\)：折扣因子（Discount Factor）。 传统监督学习（SL）解决的是“单步静态映射”问题，模型只能评估单步输出与真值标签的瞬时损失；而顺序决策面临的核心困难是延迟奖励（Delayed Reward）与信用分配问题（Credit Assignment Problem）——智能体在第 0 步下的关键决策，可能要到第 100 步才爆发全局回报（如围棋的神之一手，或大模型推理链生成最终正确答案）。 MDP 与 Bellman 递推解决的核心工程问题是：如何将无限时域或长程序列的全局累积收益，递归拆解为局部可观测的即时奖励与下一状态价值，建立起时序差分学习与策略优化的闭环数学方程。

2. 它如何工作

MDP 状态转移与逆序回报递推流程如图 1-1 与图 1-2 所示：

  1. 轨迹的累积折扣回报（Cumulative Discounted Return）： 在一条从时刻 \(t\) 到终止时刻 \(T\) 的完整轨迹采样中，折扣回报定义为未来所有奖励的加权和： \[ G_t = \sum_{k=0}^{T - t - 1} \gamma^k r_{t+k} = r_t + \gamma r_{t+1} + \gamma^2 r_{t+2} + \dots \] 这一公式天然具备反向递推（Backward Recurrence）结构： \[ G_t = r_t + \gamma G_{t+1} \quad (\text{终止步边界条件: } G_T = 0) \] 如图 1-2 所示，算法只需从轨迹末端 \(T-1\) 向前进行单遍线性扫描（时间复杂度 \(O(T)\)），即可一次性精准求出所有时刻的真实回报。
  2. 状态价值与 Bellman 期望方程（Bellman Expectation Equation）： 状态价值函数 \(V^\pi(s)\) 定义为在策略 \(\pi\) 下从状态 \(s\) 出发所能获得的累积回报的数学期望： \[ V^\pi(s) = \mathbb{E}_\pi [G_t \mid s_t = s] \] 利用条件期望全概率公式，将其递归展开为贝尔曼期望方程： \[ V^\pi(s) = \sum_{a \in \mathcal{A}} \pi(a \mid s) \left[ \mathcal{R}(s, a) + \gamma \sum_{s' \in \mathcal{S}} \mathcal{P}(s' \mid s, a) V^\pi(s') \right] \] 这证明了：当前状态的长期价值等于当前即时奖励期望加上下一状态长期价值的折现期望。

3. 正确性条件与常见误区

  • 终止（Terminated）vs 截断（Truncated）的致命混淆： 在 Gym/Gymnasium 及大模型训练中，环境返回的 done 信号包含两种截然相反的语义：
    • terminated = True：代表任务自然到达客观终止状态（如游戏通关、撞墙死机、或 LLM 生成了 <|end_of_text|> 结束符）。此时智能体在物理上再无未来，其后续价值严格为零（\(V(s_{T}) = 0\)）；
    • truncated = True：代表仅因工程人为限制（如超时超步、最大 Token 上限限制 max_seq_len）而强行切断采样。物理环境本可继续运行，因此绝对不能将截断末端的价值置零，必须通过价值网络对真实末状态进行自举（Bootstrap: \(G_{T-1} = r_{T-1} + \gamma V(s_{T})\)），否则会导致灾难性的价值系统性低估。
  • 折扣因子 \(\gamma\) 的大模型语义异化： 在传统游戏控制中，\(\gamma < 1\)（如 0.99）用于防止无穷时域回报发散；但在大语言模型（LLM）后训练（如 RLHF / PPO / GRPO）中，序列时域天然是有限的（最大上下文窗口），且核心目标是保证回答的最终准确率。此时通常强制设置 \(\gamma = 1.0\)。若盲目设置 \(\gamma < 1\)，会导致模型产生严重的“近视短视倾向”（倾向于生成简短的草率回答，惩罚深度长思考推理链）。

4. 性能与工程取舍

  • 反向动规（\(O(T)\)）vs 正向朴素求和（\(O(T^2)\)）： 若在每个时刻 \(t\) 独立向后切片求和 \(\sum_{k=0}^{T-t-1} \gamma^k r_{t+k}\)，计算复杂度为 \(O(T^2)\)。对于长度 \(T = 4096\) 的长文本轨迹，计算量高达数千万次浮点运算；而采用本课代码实现的自后向前一维递推扫描（Reverse Linear Scan），只需 \(O(T)\) 线性时间与常数内存，性能提升数百倍。
  • 折扣因子 \(\gamma\) 的方差-偏差权衡（Variance-Bias Dilemma）： \(\gamma\) 越接近 1，智能体越具远见，对长程 delayed reward 建模越充分，但蒙特卡洛采样的方差巨大，需要海量样本才能收敛；\(\gamma\) 越小，有效时域越短，累积回报方差越低，训练稳定性提升，但由于过早衰减未来，可能完全学不会需要长期前置铺垫的复杂全局策略。

奖励 [1, 0, 2]、γ=0.9 时，反向得到 G₂=2、G₁=1.8、G₀=2.62。

单轮语言模型生成也能写成 MDP：状态 sₜ=(prompt, 已生成前缀)，动作 aₜ=下一个 token，转移是把 token 拼到前缀，EOS 结束轨迹。策略是 token 分布；纯文本拼接转移确定，不意味着策略确定。工具调用后的观测则可能来自随机或变化的环境。

若只在回答完成后给奖励，也可以用 contextual bandit：prompt x 是上下文，完整回答 y 是一个动作。两种写法使用同一个自回归模型，且 logπ(y|x)=Σₜ logπ(yₜ|x,y<ₜ)。结果奖励可在 token MDP 的末步发放；过程奖励在中间推理步骤发放，不等于每个 token 都有独立质量标签。

LLM 后训练常取 γ=1；若末端正确性奖励为 1、前面全为 0，则每个位置的未折扣 return 都为 1。取 γ<1 会改变长短回答的回报权重，不能不加说明地沿用。

Q1 参考答案

  1. 输入阶段（时序交互与五元组采样）：输入由智能体与环境交互产生的时序转移轨迹，包含状态序列 \(s_0, s_1, \dots, s_T\)、动作序列 \(a_0, a_1, \dots, a_{T-1}\)、即时标量奖励 \(r_0, r_1, \dots, r_{T-1}\)、终止与截断标志位 done，以及系统配置的超参数折扣因子 \(\gamma\)。对于 LLM 生成任务，输入则是包含 Prompt 与已生成 Token 前缀的状态、下一个生成 Token 作为动作、以及环境评测器给出的最终/过程标量打分。
  2. 状态变化阶段（逆序回溯与期望展开）：
    • 轨迹样本层（反向动态规划递推）：根据图 1-2 所示流程，从末端边界条件 \(G_T = 0\)（或截断时的价值自举 \(V(s_T)\)）开始，利用 Bellman 样本递归关系 \(G_t = r_t + \gamma G_{t+1}\)，从 \(T-1\) 逆序递推回时刻 0。此过程将远端延迟奖励通过折现因子因果性地分配给历史的所有前置决策步；
    • 状态空间期望层（Bellman 期望递推）：将单条轨迹的样本递推推广到整体策略与转移概率分布空间，应用全概率公式展开为 \(V^\pi(s) = \sum_a \pi(a|s) [R(s,a) + \gamma \sum_{s'} P(s'|s,a) V^\pi(s')]\)。这在当前状态价值与下一时刻状态价值之间建立了递归自洽的守恒约束方程。
  3. 输出阶段（基线校准与信用信号）：输出每个时序步的高质量累积折现回报序列 \([G_0, G_1, \dots, G_{T-1}]\)，以及拟合收敛的状态价值 \(V(s)\)。这为后续 Policy Gradient、PPO 或 Actor-Critic 算法提供了计算优势函数 \(A(s, a) = Q(s, a) - V(s)\) 的绝对参照基准，彻底消解了延迟奖励带来的信用分配难题。

Q2 参考答案

将超时截断（Truncation）错误当作物理终止（Termination）并将末端价值强行置零（\(V(s_T) = 0\)），会产生严重的系统性价值低估偏差（Negative Value Bias）： 1. 数学本质破坏：物理终止代表系统彻底进入吸收态（Absorbing State），物理上再无任何后续转移与奖励，其未来真实价值严格为 0；而截断只是由于人为工程限制（如达到环境最大步数限制 max_steps 或 LLM max_new_tokens），当前状态 \(s_T\) 依然具有丰富的未来潜在价值（\(V^*(s_T) > 0\)）。 2. 信用分配歪曲：若强行置零，会导致末端倒数若干步的折现回报 \(G_{T-1} = r_{T-1} + \gamma \times 0\) 丢失了本应继承的 \(\gamma V(s_T)\)，使得智能体误以为接近时间限制的状态是“极度危险或极其糟糕”的，诱导策略在临近截断时产生病态的自杀行为或逃避行为。 3. 正确工程实践：环境步满截断时，必须通过当前 Critic 价值网络对末状态 \(s_T\) 进行自举（Bootstrap: \(G_t^{\text{bootstrap}} = r_{T-1} + \gamma V(s_T)\)），且绝对不能用环境在 reset() 之后产出的新 episode 起始状态来做自举。

Q3 参考答案

若即时奖励全部等比例放大 100 倍（\(r' = 100r\)），在理论最优性与实际深度强化学习训练动态中呈现出显著的分离： 1. 理论最优策略不变：根据马尔可夫决策过程的线性性质，由于 \(G'_t = 100 G_t\)，\(Q'_*(s, a) = 100 Q_*(s, a)\)，对于任意动作 \(a_1, a_2\)，若 \(Q_*(s, a_1) > Q_*(s, a_2)\)，则依然严格有 \(Q'_*(s, a_1) > Q'_*(s, a_2)\)，最优策略 \(\pi^* = \arg\max_a Q^*(s, a)\) 的理论极值点保持完全一致。 2. 神经网络优化动态剧烈恶化： - 价值网络损失膨胀万倍：Critic 价值网络的均方误差损失为 \(\mathcal{L}_V = (V_\phi(s) - G_t)^2\)。回报放大 100 倍会导致损失梯度直接放大 \(100^2 = 10^4\) 倍（一万倍），使得使用标准优化器（如 Adam, LR=\(10^{-3}\)）的神经网络瞬间发生梯度爆炸、权重溢出或激活值饱和； - 策略梯度范数失衡：未进行方差标准化的策略梯度 \(\nabla_\theta \mathcal{J} \approx \mathbb{E}[\nabla_\theta \log \pi_\theta(a|s) \cdot A(s, a)]\) 会直接放大 100 倍，导致单步参数更新过大破坏策略； - 正则化与惩罚项相对失真：若算法中包含未经缩放的固定超参数（如 PPO 中的熵正则系数 \(\beta_{\text{ent}} H(\pi)\)，或 RLHF 中与参考模型对齐的固定系数 KL 惩罚 \(\beta_{\text{KL}} D_{\text{KL}}(\pi || \pi_{\text{ref}})\)），奖励放大 100 倍将使得原有的 KL 惩罚或熵正则相对于奖励信号被削弱为原本的 \(1/100\)，导致探索过早崩塌或发生灾难性策略漂移（Reward Hacking）。因此，工业界在调节奖励尺度时必须同步调整网络学习率或对 Advantage/Return 实施 Running Normalization。

```{mermaid}
        S_prime -->|折现累加 γ| G["未来回报 G_t = r + γ V(s')"]
    end
```

### 1. 它是什么，解决什么问题

强化学习（Reinforcement Learning）的数学基石是**马尔可夫决策过程（Markov Decision Process, MDP）**。一个标准的离散时间 MDP 由五元组构成：
$$ \mathcal{M} = \langle \mathcal{S}, \mathcal{A}, \mathcal{P}, \mathcal{R}, \gamma \rangle $$
- $\mathcal{S}$：状态空间（State Space），必须满足马尔可夫性质：$P(s_{t+1} \mid s_t, a_t, \dots, s_0, a_0) = P(s_{t+1} \mid s_t, a_t)$，即“未来独立于过去，仅取决于现在”；
- $\mathcal{A}$：动作空间（Action Space）；
- $\mathcal{P}(s' \mid s, a)$：环境状态转移概率矩阵；
- $\mathcal{R}(s, a)$：即时奖励函数（Immediate Reward）；
- $\gamma \in [0, 1]$：折扣因子（Discount Factor）。
传统监督学习（SL）解决的是“单步静态映射”问题，模型只能评估单步输出与真值标签的瞬时损失；而顺序决策面临的核心困难是**延迟奖励（Delayed Reward）与信用分配问题（Credit Assignment Problem）**——智能体在第 0 步下的关键决策，可能要到第 100 步才爆发全局回报（如围棋的神之一手，或大模型推理链生成最终正确答案）。
MDP 与 Bellman 递推解决的核心工程问题是：**如何将无限时域或长程序列的全局累积收益，递归拆解为局部可观测的即时奖励与下一状态价值，建立起时序差分学习与策略优化的闭环数学方程**。

### 2. 它如何工作

MDP 状态转移与逆序回报递推流程如图 1-1 与图 1-2 所示：

1. **轨迹的累积折扣回报（Cumulative Discounted Return）**：
   在一条从时刻 $t$ 到终止时刻 $T$ 的完整轨迹采样中，折扣回报定义为未来所有奖励的加权和：
   $$ G_t = \sum_{k=0}^{T - t - 1} \gamma^k r_{t+k} = r_t + \gamma r_{t+1} + \gamma^2 r_{t+2} + \dots $$
   这一公式天然具备**反向递推（Backward Recurrence）结构**：
   $$ G_t = r_t + \gamma G_{t+1} \quad (\text{终止步边界条件: } G_T = 0) $$
   如图 1-2 所示，算法只需从轨迹末端 $T-1$ 向前进行单遍线性扫描（时间复杂度 $O(T)$），即可一次性精准求出所有时刻的真实回报。
2. **状态价值与 Bellman 期望方程（Bellman Expectation Equation）**：
   状态价值函数 $V^\pi(s)$ 定义为在策略 $\pi$ 下从状态 $s$ 出发所能获得的累积回报的数学期望：
   $$ V^\pi(s) = \mathbb{E}_\pi [G_t \mid s_t = s] $$
   利用条件期望全概率公式，将其递归展开为贝尔曼期望方程：
   $$ V^\pi(s) = \sum_{a \in \mathcal{A}} \pi(a \mid s) \left[ \mathcal{R}(s, a) + \gamma \sum_{s' \in \mathcal{S}} \mathcal{P}(s' \mid s, a) V^\pi(s') \right] $$
   这证明了：当前状态的长期价值等于**当前即时奖励期望加上下一状态长期价值的折现期望**。

### 3. 正确性条件与常见误区

- **终止（Terminated）vs 截断（Truncated）的致命混淆**：
  在 Gym/Gymnasium 及大模型训练中，环境返回的 `done` 信号包含两种截然相反的语义：
  - `terminated = True`：代表任务自然到达客观终止状态（如游戏通关、撞墙死机、或 LLM 生成了 `<|end_of_text|>` 结束符）。此时智能体在物理上再无未来，其后续价值**严格为零**（$V(s_{T}) = 0$）；
  - `truncated = True`：代表仅因工程人为限制（如超时超步、最大 Token 上限限制 `max_seq_len`）而强行切断采样。物理环境本可继续运行，因此绝对不能将截断末端的价值置零，必须通过价值网络对真实末状态进行自举（Bootstrap: $G_{T-1} = r_{T-1} + \gamma V(s_{T})$），否则会导致灾难性的价值系统性低估。
- **折扣因子 $\gamma$ 的大模型语义异化**：
  在传统游戏控制中，$\gamma < 1$（如 0.99）用于防止无穷时域回报发散；但在大语言模型（LLM）后训练（如 RLHF / PPO / GRPO）中，序列时域天然是有限的（最大上下文窗口），且核心目标是保证回答的最终准确率。此时通常强制设置 $\gamma = 1.0$。若盲目设置 $\gamma < 1$，会导致模型产生严重的“近视短视倾向”（倾向于生成简短的草率回答，惩罚深度长思考推理链）。

### 4. 性能与工程取舍

- **反向动规（$O(T)$）vs 正向朴素求和（$O(T^2)$）**：
  若在每个时刻 $t$ 独立向后切片求和 $\sum_{k=0}^{T-t-1} \gamma^k r_{t+k}$，计算复杂度为 $O(T^2)$。对于长度 $T = 4096$ 的长文本轨迹，计算量高达数千万次浮点运算；而采用本课代码实现的自后向前一维递推扫描（Reverse Linear Scan），只需 $O(T)$ 线性时间与常数内存，性能提升数百倍。
- **折扣因子 $\gamma$ 的方差-偏差权衡（Variance-Bias Dilemma）**：
  $\gamma$ 越接近 1，智能体越具远见，对长程 delayed reward 建模越充分，但蒙特卡洛采样的方差巨大，需要海量样本才能收敛；$\gamma$ 越小，有效时域越短，累积回报方差越低，训练稳定性提升，但由于过早衰减未来，可能完全学不会需要长期前置铺垫的复杂全局策略。

## 具体演示：从轨迹回报到 LLM 生成

奖励 `[1, 0, 2]`、γ=0.9 时，反向得到 G₂=2、G₁=1.8、G₀=2.62。

单轮语言模型生成也能写成 MDP：状态 sₜ=(prompt, 已生成前缀)，动作 aₜ=下一个 token，转移是把 token 拼到前缀，EOS 结束轨迹。策略是 token 分布；纯文本拼接转移确定，不意味着策略确定。工具调用后的观测则可能来自随机或变化的环境。

若只在回答完成后给奖励，也可以用 contextual bandit：prompt x 是上下文，完整回答 y 是一个动作。两种写法使用同一个自回归模型，且 logπ(y|x)=Σₜ logπ(yₜ|x,y<ₜ)。结果奖励可在 token MDP 的末步发放；过程奖励在中间推理步骤发放，不等于每个 token 都有独立质量标签。

LLM 后训练常取 γ=1；若末端正确性奖励为 1、前面全为 0，则每个位置的未折扣 return 都为 1。取 γ<1 会改变长短回答的回报权重，不能不加说明地沿用。

### Q1 参考答案

1. **输入阶段（时序交互与五元组采样）**：输入由智能体与环境交互产生的时序转移轨迹，包含状态序列 $s_0, s_1, \dots, s_T$、动作序列 $a_0, a_1, \dots, a_{T-1}$、即时标量奖励 $r_0, r_1, \dots, r_{T-1}$、终止与截断标志位 `done`，以及系统配置的超参数折扣因子 $\gamma$。对于 LLM 生成任务，输入则是包含 Prompt 与已生成 Token 前缀的状态、下一个生成 Token 作为动作、以及环境评测器给出的最终/过程标量打分。
2. **状态变化阶段（逆序回溯与期望展开）**：
   - **轨迹样本层（反向动态规划递推）**：根据图 1-2 所示流程，从末端边界条件 $G_T = 0$（或截断时的价值自举 $V(s_T)$）开始，利用 Bellman 样本递归关系 $G_t = r_t + \gamma G_{t+1}$，从 $T-1$ 逆序递推回时刻 0。此过程将远端延迟奖励通过折现因子因果性地分配给历史的所有前置决策步；
   - **状态空间期望层（Bellman 期望递推）**：将单条轨迹的样本递推推广到整体策略与转移概率分布空间，应用全概率公式展开为 $V^\pi(s) = \sum_a \pi(a|s) [R(s,a) + \gamma \sum_{s'} P(s'|s,a) V^\pi(s')]$。这在当前状态价值与下一时刻状态价值之间建立了递归自洽的守恒约束方程。
3. **输出阶段（基线校准与信用信号）**：输出每个时序步的高质量累积折现回报序列 $[G_0, G_1, \dots, G_{T-1}]$，以及拟合收敛的状态价值 $V(s)$。这为后续 Policy Gradient、PPO 或 Actor-Critic 算法提供了计算优势函数 $A(s, a) = Q(s, a) - V(s)$ 的绝对参照基准，彻底消解了延迟奖励带来的信用分配难题。

### Q2 参考答案

将超时截断（Truncation）错误当作物理终止（Termination）并将末端价值强行置零（$V(s_T) = 0$），会产生严重的**系统性价值低估偏差（Negative Value Bias）**：
1. **数学本质破坏**：物理终止代表系统彻底进入吸收态（Absorbing State），物理上再无任何后续转移与奖励，其未来真实价值严格为 0；而截断只是由于人为工程限制（如达到环境最大步数限制 `max_steps` 或 LLM `max_new_tokens`），当前状态 $s_T$ 依然具有丰富的未来潜在价值（$V^*(s_T) > 0$）。
2. **信用分配歪曲**：若强行置零，会导致末端倒数若干步的折现回报 $G_{T-1} = r_{T-1} + \gamma \times 0$ 丢失了本应继承的 $\gamma V(s_T)$，使得智能体误以为接近时间限制的状态是“极度危险或极其糟糕”的，诱导策略在临近截断时产生病态的自杀行为或逃避行为。
3. **正确工程实践**：环境步满截断时，必须通过当前 Critic 价值网络对末状态 $s_T$ 进行自举（Bootstrap: $G_t^{\text{bootstrap}} = r_{T-1} + \gamma V(s_T)$），且绝对不能用环境在 `reset()` 之后产出的新 episode 起始状态来做自举。

### Q3 参考答案

若即时奖励全部等比例放大 100 倍（$r' = 100r$），在理论最优性与实际深度强化学习训练动态中呈现出显著的分离：
1. **理论最优策略不变**：根据马尔可夫决策过程的线性性质，由于 $G'_t = 100 G_t$，$Q'_*(s, a) = 100 Q_*(s, a)$，对于任意动作 $a_1, a_2$，若 $Q_*(s, a_1) > Q_*(s, a_2)$，则依然严格有 $Q'_*(s, a_1) > Q'_*(s, a_2)$，最优策略 $\pi^* = \arg\max_a Q^*(s, a)$ 的理论极值点保持完全一致。
2. **神经网络优化动态剧烈恶化**：
   - **价值网络损失膨胀万倍**：Critic 价值网络的均方误差损失为 $\mathcal{L}_V = (V_\phi(s) - G_t)^2$。回报放大 100 倍会导致损失梯度直接放大 $100^2 = 10^4$ 倍（一万倍），使得使用标准优化器（如 Adam, LR=$10^{-3}$）的神经网络瞬间发生梯度爆炸、权重溢出或激活值饱和；
   - **策略梯度范数失衡**：未进行方差标准化的策略梯度 $\nabla_\theta \mathcal{J} \approx \mathbb{E}[\nabla_\theta \log \pi_\theta(a|s) \cdot A(s, a)]$ 会直接放大 100 倍，导致单步参数更新过大破坏策略；
   - **正则化与惩罚项相对失真**：若算法中包含未经缩放的固定超参数（如 PPO 中的熵正则系数 $\beta_{\text{ent}} H(\pi)$，或 RLHF 中与参考模型对齐的固定系数 KL 惩罚 $\beta_{\text{KL}} D_{\text{KL}}(\pi || \pi_{\text{ref}})$），奖励放大 100 倍将使得原有的 KL 惩罚或熵正则相对于奖励信号被削弱为原本的 $1/100$，导致探索过早崩塌或发生灾难性策略漂移（Reward Hacking）。因此，工业界在调节奖励尺度时必须同步调整网络学习率或对 Advantage/Return 实施 Running Normalization。
