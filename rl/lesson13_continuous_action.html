核心心智模型

1. 离散 Token 概率 vs 连续物理动作空间

在大模型后训练（如 DeepSeek-R1、ChatGPT RLHF）中，策略网络在每一步输出词表大小（|𝒱|≈128000|\mathcal{V}| \approx 128000）的离散 Softmax 概率分布，采样得到单个整数 Token ID。

但在机械臂或自动驾驶中，动作是多维实数向量（Continuous Action Vector）： a∈[−1.0,1.0]Da \in [-1.0, 1.0]^D 例如机械臂的 7 个关节目标力矩或转速。如果简单地将连续区间离散化为网格，维度诅咒（Curse of Dimensionality）会导致动作空间呈指数级爆炸（107=100010^7 = 1000 万种组合），策略梯度根本无法收敛！

图 13-1：连续动作空间高斯策略建模、边界压缩与平滑惩罚体系

2. Tanh 边界压缩的数学陷阱：雅可比行列式修正

为了将无界的高斯采样值 u∈(−∞,+∞)u \in (-\infty, +\infty) 限制在真实电机的物理安全范围 [−1,1][-1, 1] 内，标准做法是使用双曲正切函数： a=tanh⁡(u)a = \tanh(u)

根据概率论的随机变量换元定理（Change of Variables Theorem），对于非线性单射变换 a=g(u)a = g(u)，其概率密度函数满足： pA(a)=pU(u)⋅|dg(u)du|−1p_A(a) = p_U(u) \cdot \left| \frac{d g(u)}{d u} \right|^{-1}

对数概率必须显式扣除雅可比导数项： log⁡π(a∣s)=log⁡π(u∣s)−∑i=1Dlog⁡(1−tanh⁡2(ui)+ϵ)\log \pi(a \mid s) = \log \pi(u \mid s) - \sum_{i=1}^D \log\left(1 - \tanh^2(u_i) + \epsilon\right)

  • 致命警示：如果漏掉这一项（直接将 log⁡π(u∣s)\log \pi(u \mid s) 当作实际动作概率），会导致越靠近边界（a→±1a \to \pm 1）的状态熵被极其严重的病态高估，策略会过早将动作死锁在最大极限位置，导致电机堵转烧毁。

class ContinuousActionPolicy:
    def __init__(self, action_dim=7):
        self.action_dim = action_dim

    def sample_action(self, mean, log_std, noise=None):
        std = np.exp(log_std)
        if noise is None:
            noise = np.random.normal(0, 1.0, size=mean.shape)
            
        # 1. 重参数化高斯隐变量: u = mean + std * noise
        u = mean + std * noise
        
        # 2. 非线性 Tanh 压缩至 [-1, 1] 物理区间
        action = np.tanh(u)
        
        # 3. 高斯未压缩对数概率 log p(u)
        # log N(u; mu, sigma) = -0.5 * [ ((u-mu)/sigma)^2 + 2*log_std + log(2*pi) ]
        var = np.square(std)
        log_prob_u = -0.5 * (np.square(u - mean) / var + 2.0 * log_std + np.log(2.0 * np.pi))
        log_prob_u = np.sum(log_prob_u, axis=-1)  # 对动作各维度求和
        
        # 4. 换元定理雅可比行列式微积分修正: - sum( log(1 - a^2 + eps) )
        # 引入 1e-6 防止边界 a = +-1 时 log(0) 产生 -inf
        jacobian_term = np.sum(np.log(np.clip(1.0 - np.square(action), 1e-6, 1.0)), axis=-1)
        
        # 真实动作对数概率
        log_prob = log_prob_u - jacobian_term
        return action, log_prob

    def compute_smoothness_penalty(self, action_seq, lambda_smooth=0.1, lambda_jerk=0.05):
        assert len(action_seq) >= 3, "需要至少 3 步历史动作计算一阶与二阶差分"
        a_t2, a_t1, a_t0 = action_seq[-3], action_seq[-2], action_seq[-1]
        
        # 一阶差分速度变化: ||a_t - a_{t-1}||^2
        diff1 = a_t0 - a_t1
        smooth_loss = np.sum(np.square(diff1))
        
        # 二阶差分加速度/急加度变化 (Jerk): ||a_t - 2*a_{t-1} + a_{t-2}||^2
        diff2 = a_t0 - 2.0 * a_t1 + a_t2
        jerk_loss = np.sum(np.square(diff2))
        
        total_cost = float(lambda_smooth * smooth_loss + lambda_jerk * jerk_loss)
        return total_cost

Q1 参考答案

  1. Tanh 高斯的边界数值饱和与对数奇点： 当高斯隐变量 |u|>3|u| > 3 时，tanh⁡(u)\tanh(u) 极速逼近 ±1\pm 1。此时其导数 1−tanh⁡2(u)→01 - \tanh^2(u) \to 0。在微积分雅可比修正项 −log⁡(1−a2)-\log(1 - a^2) 中，真数接近 0 导致修正项趋于负无穷大。在反向传播时，梯度极易发生极端截断，导致策略一旦陷入动作边界就无法再通过梯度更新探索内部区域。
  2. Beta 分布的原生有界性与良好梯度： Beta 分布天然定义在闭区间 [0,1][0, 1] 上（可通过线性仿射缩放到 [−1,1][-1, 1]）。它由两个正数参数 α,β\alpha, \beta 完全确定。无论参数如何变化，其支撑集始终严格在紧凑域内部，完全不需要经过非线性的 Tanh 压缩，因而彻底免除了雅可比行列式修正项，消除了数值奇点与边界饱和死锁。

Q2 参考答案

  1. 仿真物理引擎的时间步离散缺陷： 在物理仿真器（如 MuJoCo 或 Isaac Sim）中，时间以离散步长（如 20ms）积分。如果神经网络在每一步直接给出最大正向力矩 +1.0+1.0，下一步给出最大反向力矩 −1.0-1.0（即 Bang-Bang 控制），在数学上能够以最快速度克服刚体惯性，从而在不考虑物理损耗的仿真中刷出极高的目标达成奖励。
  2. 真实电机的物理毁灭： 物理电机的电感和磁通具有响应时间，机械齿轮之间存在微小的啮合间隙（Backlash）。高频的极值反转会在齿轮齿面上产生剧烈的刚性撞击（冲击力可达额定力矩的数十倍），导致减速器齿轮瞬间崩齿断裂，驱动器功率 MOSFET 管因反向电动势过流击穿烧毁。加入一阶平滑与二阶急加度（Jerk）惩罚，能够强制网络学习出符合物理动力学规律的平滑加减速曲线。

Q3 参考答案

  1. 传统 CPU 仿真调度的严重跨总线瓶颈： 传统强化学习（如旧版 Gym）每个仿真环境运行在 CPU 上，每一步需要：CPU 模拟物理 -> PCIe 上传状态 -> GPU 网络推理 -> PCIe 下载动作 -> CPU 推进仿真。对于数千个环境，PCIe 搬运与 CPU 线程调度开销吃掉了 95% 以上的时间，GPU 计算核利用率不足 5%。
  2. GPU 原生全片上物理仿真闭环（GPU-native Rollout）： 现代 GPU 仿真框架（如 Isaac Gym、Isaac Lab、MuJoCo XLA）直接将上万个机器人刚体关节物理引擎完全写为 CUDA 内核并部署在 GPU 显存中。 每一步的观测状态张量 obs 直接保存在 GPU HBM 中，Actor 网络直接以批处理形式原地前向推理，输出的动作张量 actions 零拷贝直接送入下一个物理步进 CUDA 内核。全程零 PCIe 往返、零 CPU 介入，使得环境交互吞吐直接突破每秒数十万帧！

## 核心心智模型

### 1. 离散 Token 概率 vs 连续物理动作空间

在大模型后训练（如 DeepSeek-R1、ChatGPT RLHF）中，策略网络在每一步输出词表大小（$|\mathcal{V}| \approx 128000$）的离散 Softmax 概率分布，采样得到单个整数 Token ID。

但在机械臂或自动驾驶中，动作是**多维实数向量（Continuous Action Vector）**：
$$a \in [-1.0, 1.0]^D$$
例如机械臂的 7 个关节目标力矩或转速。如果简单地将连续区间离散化为网格，维度诅咒（Curse of Dimensionality）会导致动作空间呈指数级爆炸（$10^7 = 1000$ 万种组合），策略梯度根本无法收敛！

### 2. Tanh 边界压缩的数学陷阱：雅可比行列式修正

为了将无界的高斯采样值 $u \in (-\infty, +\infty)$ 限制在真实电机的物理安全范围 $[-1, 1]$ 内，标准做法是使用双曲正切函数：
$$a = \tanh(u)$$

根据概率论的**随机变量换元定理（Change of Variables Theorem）**，对于非线性单射变换 $a = g(u)$，其概率密度函数满足：
$$p_A(a) = p_U(u) \cdot \left| \frac{d g(u)}{d u} \right|^{-1}$$

对数概率必须显式扣除雅可比导数项：
$$\log \pi(a \mid s) = \log \pi(u \mid s) - \sum_{i=1}^D \log\left(1 - \tanh^2(u_i) + \epsilon\right)$$

- **致命警示**：如果漏掉这一项（直接将 $\log \pi(u \mid s)$ 当作实际动作概率），会导致越靠近边界（$a \to \pm 1$）的状态熵被极其严重的病态高估，策略会过早将动作死锁在最大极限位置，导致电机堵转烧毁。

```python
class ContinuousActionPolicy:
    def __init__(self, action_dim=7):
        self.action_dim = action_dim

    def sample_action(self, mean, log_std, noise=None):
        std = np.exp(log_std)
        if noise is None:
            noise = np.random.normal(0, 1.0, size=mean.shape)
            
        # 1. 重参数化高斯隐变量: u = mean + std * noise
        u = mean + std * noise
        
        # 2. 非线性 Tanh 压缩至 [-1, 1] 物理区间
        action = np.tanh(u)
        
        # 3. 高斯未压缩对数概率 log p(u)
        # log N(u; mu, sigma) = -0.5 * [ ((u-mu)/sigma)^2 + 2*log_std + log(2*pi) ]
        var = np.square(std)
        log_prob_u = -0.5 * (np.square(u - mean) / var + 2.0 * log_std + np.log(2.0 * np.pi))
        log_prob_u = np.sum(log_prob_u, axis=-1)  # 对动作各维度求和
        
        # 4. 换元定理雅可比行列式微积分修正: - sum( log(1 - a^2 + eps) )
        # 引入 1e-6 防止边界 a = +-1 时 log(0) 产生 -inf
        jacobian_term = np.sum(np.log(np.clip(1.0 - np.square(action), 1e-6, 1.0)), axis=-1)
        
        # 真实动作对数概率
        log_prob = log_prob_u - jacobian_term
        return action, log_prob

    def compute_smoothness_penalty(self, action_seq, lambda_smooth=0.1, lambda_jerk=0.05):
        assert len(action_seq) >= 3, "需要至少 3 步历史动作计算一阶与二阶差分"
        a_t2, a_t1, a_t0 = action_seq[-3], action_seq[-2], action_seq[-1]
        
        # 一阶差分速度变化: ||a_t - a_{t-1}||^2
        diff1 = a_t0 - a_t1
        smooth_loss = np.sum(np.square(diff1))
        
        # 二阶差分加速度/急加度变化 (Jerk): ||a_t - 2*a_{t-1} + a_{t-2}||^2
        diff2 = a_t0 - 2.0 * a_t1 + a_t2
        jerk_loss = np.sum(np.square(diff2))
        
        total_cost = float(lambda_smooth * smooth_loss + lambda_jerk * jerk_loss)
        return total_cost

# 验证执行
```

### Q1 参考答案

1. **Tanh 高斯的边界数值饱和与对数奇点**：
   当高斯隐变量 $|u| > 3$ 时，$\tanh(u)$ 极速逼近 $\pm 1$。此时其导数 $1 - \tanh^2(u) \to 0$。在微积分雅可比修正项 $-\log(1 - a^2)$ 中，真数接近 0 导致修正项趋于负无穷大。在反向传播时，梯度极易发生极端截断，导致策略一旦陷入动作边界就无法再通过梯度更新探索内部区域。
2. **Beta 分布的原生有界性与良好梯度**：
   Beta 分布天然定义在闭区间 $[0, 1]$ 上（可通过线性仿射缩放到 $[-1, 1]$）。它由两个正数参数 $\alpha, \beta$ 完全确定。无论参数如何变化，其支撑集始终严格在紧凑域内部，完全不需要经过非线性的 Tanh 压缩，因而彻底免除了雅可比行列式修正项，消除了数值奇点与边界饱和死锁。

### Q2 参考答案

1. **仿真物理引擎的时间步离散缺陷**：
   在物理仿真器（如 MuJoCo 或 Isaac Sim）中，时间以离散步长（如 20ms）积分。如果神经网络在每一步直接给出最大正向力矩 $+1.0$，下一步给出最大反向力矩 $-1.0$（即 Bang-Bang 控制），在数学上能够以最快速度克服刚体惯性，从而在不考虑物理损耗的仿真中刷出极高的目标达成奖励。
2. **真实电机的物理毁灭**：
   物理电机的电感和磁通具有响应时间，机械齿轮之间存在微小的啮合间隙（Backlash）。高频的极值反转会在齿轮齿面上产生剧烈的刚性撞击（冲击力可达额定力矩的数十倍），导致减速器齿轮瞬间崩齿断裂，驱动器功率 MOSFET 管因反向电动势过流击穿烧毁。加入一阶平滑与二阶急加度（Jerk）惩罚，能够强制网络学习出符合物理动力学规律的平滑加减速曲线。

### Q3 参考答案

1. **传统 CPU 仿真调度的严重跨总线瓶颈**：
   传统强化学习（如旧版 Gym）每个仿真环境运行在 CPU 上，每一步需要：`CPU 模拟物理 -> PCIe 上传状态 -> GPU 网络推理 -> PCIe 下载动作 -> CPU 推进仿真`。对于数千个环境，PCIe 搬运与 CPU 线程调度开销吃掉了 95% 以上的时间，GPU 计算核利用率不足 5%。
2. **GPU 原生全片上物理仿真闭环（GPU-native Rollout）**：
   现代 GPU 仿真框架（如 Isaac Gym、Isaac Lab、MuJoCo XLA）直接将上万个机器人刚体关节物理引擎完全写为 CUDA 内核并部署在 GPU 显存中。
   每一步的观测状态张量 `obs` 直接保存在 GPU HBM 中，Actor 网络直接以批处理形式原地前向推理，输出的动作张量 `actions` 零拷贝直接送入下一个物理步进 CUDA 内核。全程零 PCIe 往返、零 CPU 介入，使得环境交互吞吐直接突破每秒数十万帧！
