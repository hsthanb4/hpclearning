性能剖析、死锁诊断与状态审计核心线

在以大模型、自动驾驶与具身智能为代表的复杂 AI 系统中，代码通常由多层框架封装甚至由 AI Code Agent 辅助生成。当系统遇到吞吐不及预期、进程卡死挂起、数值突发 NaN/Inf 等棘手问题时，上层框架的日志往往无能为力。

工程师最不可替代的核心竞争力，在于能够穿透封装，直接与硬件执行轨迹（Timeline）、分布式网络通信流与底层内存不变量对话。本模块专为系统级工程师打造，手把手建立起微秒级耗时归因、通信死锁逆向定位与底层状态审计的体系化实战能力。

学习目标

完成本系列 5 课实战后，你将具备：

  1. Nsight Systems (nsys) 全链路归因能力：熟练解读系统级 Timeline，逐帧诊断 CPU Launch 开销、CUDA Stream 调度、Host-Device 同步气泡（.item()、显存分配锁）并予以消除；
  2. Nsight Compute (ncu) 算子微架构调优能力：掌握 Roofline 模型与 Speed-of-Light (SOL)，精准定位 SM 活跃度瓶颈、指令发射停顿（Stalls）与访存冲突；
  3. 分布式通信死锁逆向定位能力：能够通过 NCCL_DEBUG 日志、py-spy 与 GDB 堆栈回溯，逆向还原多卡环形/树形通信挂起、P2P 异步死锁与 CUDA Stream 交叉依赖链；
  4. 低精度数值稳定性与溢出排查能力：深入 IEEE 754 底层，排查 FP8 / BF16 极窄动态范围下的下溢崩溃、梯度消失与 NaN 级联，掌握轻量级片上数值异常探测器设计；
  5. 底层不变量审计与状态自愈能力：针对 AI 辅助生成代码中常见的隐式隐患（IPC 句柄泄露、异步流悬空、跨进程显存未对齐），构建生产级状态巡检断言与运行时容错机制。
