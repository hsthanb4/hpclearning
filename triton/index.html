# Triton Kernel 核心主线

OpenAI Triton 为深度学习工程师提供了用 Python 编写高效 GPU 算子的强大工具。本主线从 Program、Block 与 Mask 基础出发，全面覆盖逐元素激活、归约、Softmax、转置、Matmul 与随机数生成。

## 学习目标

1. 深入理解 Triton 的 SPMD 执行模型与 Block 级编程思想；

2. 掌握 `tl.load` / `tl.store` 的 Boundary Mask 防护与 Padding 处理；

3. 熟练编写 Blocked Matrix Multiplication 与 FP32 累加；

4. 掌握 Triton 独有的 `tl.constexpr` 编译期常量与自动调优机制。
