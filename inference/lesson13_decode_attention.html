第 13 课：Decode Attention 深度优化：Flash-Decoding、FlashInfer 与 FlashMLA

本课目标与通过标准

掌握大模型 Decode 阶段自注意力算子的微架构瓶颈与加速范式。理解从 FlashAttention 到 Flash-Decoding（解决 q_len=1q\_len=1 访存受限与 SM 空转） 的演进，掌握跨 CTA Split-KV 归约的数学结合律；拆解 FlashInfer 的 BSR 稀疏块格式与 Plan-Run 机制；深入分析 DeepSeek MLA（Multi-Head Latent Attention） 低秩压缩与矩阵吸收（Matrix Absorption）的显存带宽跃升。

源码版本与阅读方法

聚焦 GPU 硬件 SM 占用率（Occupancy）与显存带宽利用率（MBU）。基准：FlashInfer arXiv:2501.01005、DeepSeek-V2 arXiv:2405.04434 / V3 arXiv:2412.19437；参考 deepseek-ai/FlashMLA。

顺序 核心文件与模块 带着什么问题读
1 Flash-Decoding 官方实现 为什么沿 KV 维度切开后，局部 (mi,li,acci)(m_i, l_i, \text{acc}_i) 能无偏融合成精确全局 Softmax？
2 FlashInfer flashinfer/attention/ FlashInfer 如何用统一 BSR 格式处理 Paged KV Cache 与 Ragged Batch？
3 FlashMLA deepseek-ai/FlashMLA C++ Hopper TMA 与 WGMMA 在处理 MLA 低秩投影时的 Tile 切分与流水线设计？
4 vLLM vllm/v1/attention/backends/ 推理引擎如何根据 Batch Size 和 Sequence Length 动态在常规 Attention 与 Split-KV 切换？
