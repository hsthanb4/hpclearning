第 8 课：现代 Speculative Systems：EAGLE-3、MTP、DFlash 与硬件 Roofline 边界

本课目标与通过标准

掌握现代大模型投机推理系统（Speculative Systems）的全栈工程架构。深入对比传统独立 Drafter、EAGLE-3（多层融合隐层外推）、DeepSeek MTP（原生多 Token 预测） 与 DFlash（非自回归并行迸发） 的提议临界路径；掌握 Tree Attention 验证与原子 KV 回滚；建立基于硬件 Roofline 模型的大 Batch 收益边界认知，能够准确定位投机加速由正收益翻转为算力受限负收益的工程临界点。

源码版本与阅读方法

控制流与验证状态机阅读法。先理清草稿提议者（Proposer）与主模型验证者（Verifier）的职责边界，再跟踪分支采纳与 KV 回滚的状态所有权流转。基准：vLLM 8e958902eee5、SGLang 9deb6952afa4；论文 EAGLE-3 arXiv:2503.01840、DFlash arXiv:2602.06036。

顺序 核心文件与模块 带着什么问题读
1 SGLang speculative/spec_info.py 引擎如何统一抽象并注册 EAGLE、MTP、DFLASH 等投机算法？
2 SGLang eagle_worker_v2.py 多层特征融合、树状拓扑组装、Tree Mask 验证与 CUDA Graph 捕获如何协同？
3 SGLang dflash_worker_v2.py 非自回归 Block Drafter 如何在单次前向迸发出整个候选块分布？
4 vLLM v1/spec_decode/ 通用 Proposer 与 Verifier 如何解耦？未命中分支的 KV 槽位如何原子回滚？
5 SGLang dspark_worker_v2.py 调度器如何基于实时置信度与并发负载动态调整投机深度？
