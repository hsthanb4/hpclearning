第 15 课：免训练长上下文加速：KV 驱逐、动态分块与低秩稀疏

本课目标与通过标准

掌握无需微调即可作用于开源大模型的长上下文推理加速算法矩阵。区分 KV Cache 物理驱逐（永久丢弃） 与 查询感知稀疏（逻辑全量、物理按需加载） 的数学本质；深入拆解 StreamingLLM 的 Attention Sinks（注意力汇）、H2O 累积注意力驱逐与 SnapKV 观察窗口特征提炼；掌握 KIVI 非对称 2-bit KV 量化；明确各类策略与 Prefix Caching、投机采样的冲突边界。

源码版本与阅读方法

聚焦“免训练算法如何介入 KV 读写管道”。基准：StreamingLLM arXiv:2309.17453、H2O arXiv:2306.14048、SnapKV arXiv:2404.14469、KIVI arXiv:2402.02750；参考 mit-han-lab/streaming-llm、FasterDecoding/SnapKV。

顺序 核心文件与模块 带着什么问题读
1 StreamingLLM streaming_llm/kv_cache.py 初始 Token（Sink）具有锚定 Softmax 分母的何种不可替代作用？
2 H2O 累积注意力驱逐规则 累积注意力分数（Cumulative Attention Scores）如何动态指导物理块释放？
3 SnapKV snapkv/monkeypatch/ 凭 Prompt 结尾的观察窗口如何预测长文档在 Decode 期的注意力焦点？
4 Quest mit-han-lab/Quest 如何用每个 Page 的 Key 向量极值快速推导注意力得分上界？
5 KIVI jy-yuan/KIVI 量化内核 Key 沿通道与 Value 沿序列量化背后的离群值物理分布原因？
