第 12 课：Prefill 与 Decode (PD) 物理分离：架构权衡、KV 传输与分层存储

本课目标与通过标准

掌握大模型推理集群中 Prefill 与 Decode 物理分离（PD Disaggregation） 的系统设计思想与落地细节。从硬件 Roofline 推导分离根本动力，建立基于 TTFT 与 ITL 的 Goodput 优化模型，掌握跨节点 RDMA 零拷贝 KV Cache 传输与基于 DeviceMesh 的 Resharding 机制，深入分析 Mooncake 与 LMCache 的分层存储架构。

源码版本与阅读方法

控制流与数据流分离阅读法。先建立控制平面与数据平面的拓扑视图，再跟踪单请求生命周期中 KV Cache 的生成、序列化、RDMA 传输与 Decode 接收挂载。基准：vLLM 8e958902eee5、SGLang 9deb6952afa4；Mooncake arXiv:2407.00079。

顺序 核心文件与模块 带着什么问题读
1 vLLM vllm/distributed/kv_transfer/kv_connector/ P 与 D 节点如何通过统一抽象传递 KV 张量元数据？
2 SGLang python/sglang/srt/disaggregation/ 请求在调度器层面如何路由至 Prefill 并移交 Decode？
3 Mooncake kvcache-ai/Mooncake C++ 传输栈 内存池（DRAM/HBM）如何通过 RDMA 与 GDR 绕过 CPU 拷贝直通？
4 LMCache lmcache/inprocess/v1/storage_backend/ 跨节点 Prefix Cache 与历史会话如何在 HBM、DRAM、远端存储池流动？
5 DistServe distserve/ P 与 D 节点的 TP/PP 并行度与机器比例如何通过 MIP 求解？
