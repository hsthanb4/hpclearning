课程体系大纲（按推荐学习路径排序）

第一阶段：分布式显存初探与核心算子开发

排序 课程模块 课数 核心技能与产出 前置条件
01 训练系统基础篇 (Train 1~5) 5 建立大模型静态显存与激活账本，掌握激活重计算与分布式通信原语，理解 DDP 与 ZeRO-1/2/3 切分机制 Transformer 架构与基础 PyTorch

03 Triton Kernel 算子开发 10 掌握 Pythonic SPMD 编程模型、Block 级指针代数、Fused Softmax、Matmul 与 Program ID 超分组 Swizzling Python、PyTorch、基础 CUDA 概念

第二阶段：硬件微架构抽象与编译优化技术

排序 课程模块 课数 核心技能与产出 前置条件
04 CUTLASS / CuTe 模板库 8 掌握 CuTe Layout 坐标映射代数、Tiled Copy / Tiled MMA 硬件抽象、Ampere/Hopper 异步拷贝流水线与 Kernel 选型 CUDA 线程模型、C++ 模板元编程
05 MLIR 编译器技术 8 掌握多级中间表示（Multi-Level IR）、SSA 支配树、Dialect 方言体系、ODS 定义、Pattern 重写与 GPU/LLVM 逐级 Lowering 编译原理基础、C++ 源码阅读能力

第三阶段：AI Infra 运行时与端到端系统工程

排序 课程模块 课数 核心技能与产出 前置条件
06 框架运行时底层机制 8 深入剖析 PyTorch Dispatcher 分发器、TorchDynamo/Inductor 编译追踪、NCCL 环形/树形通信底层、CUDA Graph 与数据加载流水线 Python、PyTorch 源码、CUDA 基础
07 推理引擎源码与优化 8 逐行走读 vLLM V1 三层解耦架构与 SGLang 核心源码，掌握 PagedAttention、RadixAttention 缓存复用、W8A8/FP8 量化与投机采样正确性验证 训练基础、CUDA/Triton、Transformer 架构
08 智算集群平台与可靠性 8 掌握智算中心 Spine-Leaf 网络拓扑、RoCE v2 / InfiniBand RDMA 无损网络、GPUDirect Storage 分级存储、K8s 拓扑感知调度与 Daly 最优 Checkpoint 容错模型 Linux 网络/系统运维基础、分布式训练经验

第四阶段：超大规模分布式并行与对齐算法进阶

排序 课程模块 课数 核心技能与产出 前置条件
09 训练系统实战进阶 (Train 6~14) 9 深入掌握张量并行（TP）、序列并行（SP）、上下文并行（CP / Ring Attention）、流水线并行（PP 1F1B/Zero-Bubble）、专家并行（EP），精通 5D 并行协同与配置搜索 训练系统 1~5 课、算子开发基础
10 强化学习与大模型后训练 12 从 MDP、Bellman 方程、策略梯度定理与 GAE 出发，掌握 PPO、RLHF/RLVR 到 DeepSeek GRPO 组内相对奖励机制，设计工业级分布式 Rollout 采样系统 概率论与数理统计、深度学习基础
