集群平台、网络存储与可靠性

8 课 AI 智算中心集群架构、网络拓扑与调度系统

集群平台核心线

面向工业界千卡/万卡 AI 智算集群建设，深入分析硬件拓扑、高速互连网络（InfiniBand/RoCE）、分布式存储 IO、容器虚拟化与超大规模调度。

学习目标

  1. 掌握 GPU 服务器内部 NUMA、PCIe 交换、NVLink 与 NIC NUMA 亲和性；

  2. 理解 InfiniBand 与 RoCE v2 协议栈、PFC/ECN 流控与 GPUDirect RDMA；

  3. 掌握分布式存储三级缓存架构与 Checkpoint 秒级快照带宽预算；

  4. 掌握 Gang Scheduling、拓扑感知放置（Topology-Aware Placement）与故障自愈设计。

vLLM / SGLang / TensorRT-LLM 怎么讲

面试：算带宽、占用率、访存模式
B. 推理引擎
主学：scheduler + KV cache + batching
作品：mini vLLM / SGLang 源码笔记
面试：prefill/decode、paged/radix cache
C. 云端 Serving
主学：K8s + routing + observability
作品：压测 vLLM/SGLang 服务
面试：SLO、限流、扩缩容、故障恢复
D. 分布式系统
主学：TP/PP/EP + NCCL/RCCL
作品：多卡推理 benchmark
面试：通信瓶颈、拓扑、all-to-all
E. 端侧推理
主学：llama.cpp / MLC / ONNX Runtime
作品：量化和延迟报告
面试：内存预算、功耗、首 token 延迟
F. 编译器 / 框架
主学：torch.compile / Inductor / MLIR
作品：算子融合或 lowering demo
面试：图优化、autotune、codegen
选主线建议
找工作时不要六条线平均用力。
最容易形成作品集的是：Kernel 或推理引擎。
有工程背景选云端 serving；有 HPC 背景选 kernel/分布式；只有消费级 AMD 卡也能做 ROCm/Triton/端侧路线。
求职目标
能解释系统瓶颈
能 profile 和优化
能产出 benchmark / PR / 文档

四、面向简历的项目作品集
项目 1：算子优化
实现 fused RMSNorm / SwiGLU / softmax / MoE dispatch
要求：正确性测试、profile 截图、不同 shape benchmark
简历写法：延迟降低 X%，带宽利用率提升 Y%
项目 2：mini 推理引擎
实现连续 batching + KV cache block manager
可简化模型，只要调度和缓存逻辑讲清楚
简历写法：支持 prefix reuse，TTFT/ITL 可观测
项目 3：生产压测
部署 vLLM 或 SGLang OpenAI API
压测不同 batch、context、并发和量化配置
简历写法：给出容量规划和瓶颈定位
项目 4：多 GPU / AMD 路线
NVIDIA：NCCL + TP/EP benchmark
AMD：ROCm/HIP/Triton/RCCL bring-up
简历写法：跨平台 correctness + performance 调优
项目 5：源码阅读文档
vLLM：PagedAttention / prefix cache
SGLang：RadixAttention / scheduler
TensorRT-LLM：plugins / quant / batching
面试时用图解释，不只背结论
面试回答模板：技术点是什么 -> 解决哪个瓶颈 -> 数据结构/算子/调度怎么做 -> tradeoff 是什么 -> 用什么指标证明有效。所有项目都按这个模板准备。
资料来源：OpenAI inference/AMD JD、RadixArk GPU Kernel JD、NVIDIA AI Inference JD、Red Hat distributed vLLM/Kubernetes JD、vLLM/SGLang/TensorRT-LLM/Triton/CUDA/ROCm 官方文档。
